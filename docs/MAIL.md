# 중요 메일 알림

새 메일이 오면 POPME가 중요한 것만 골라 캐릭터 말풍선으로 알려줍니다. 아침 브리핑에는 "밤사이 중요 메일"이 같이 나옵니다.

## 1. Gmail 준비 (5분)

1. **2단계 인증 켜기**: [myaccount.google.com](https://myaccount.google.com) → 보안 → 2단계 인증. 이미 켜져 있으면 건너뜁니다.
2. **앱 비밀번호 만들기**: [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) → 앱 이름 `POPME` → 만들기 → 16자리 복사 (한 번만 보여줌)
   - 메일함 접근만 되고 구글 계정 설정은 못 바꾸는 비밀번호입니다. 같은 페이지에서 언제든 지울 수 있습니다.
   - 구글 비밀번호를 바꾸면 앱 비밀번호도 무효가 되니 새로 만드세요.
   - 회사·학교(Google Workspace) 계정은 관리자가 막아 두었을 수 있습니다.
3. **IMAP**: 지금 Gmail은 기본으로 켜져 있습니다. Gmail 설정 → 전달 및 POP/IMAP에 "IMAP 사용"이 보이면 켜세요.

## 2. config.toml

```toml
[mail]
enabled = true
user = "you@example.com"
password = "abcdefghijklmnop"      # 앱 비밀번호 (띄어쓰기는 빼도 되고 둬도 됨)
vip = ["boss@example.com", "국세청"]
keywords = ["긴급", "결제 실패"]
ignore = ["newsletter@"]
quiet_hours = "23:00-07:00"
```

나머지 항목과 기본값은 `config.example.toml`의 `[mail]`에 있습니다. 고친 뒤 POPME를 다시 켜면 반영됩니다. 켜지면 패널에 **메일** 탭이 생깁니다.

`config.toml`은 저장소에 올라가지 않지만, 비밀번호가 PC에 그대로(평문) 저장됩니다. 그래서 일반 비밀번호가 아닌 앱 비밀번호를 씁니다.

## 3. 동작 방식

```
메일 서버 ──(IDLE: 연결 하나를 열어 두고 대기)── POPME
  새 메일 → 몇 초 안에 신호 → batch_sec(60초) 동안 모았다가 한 번에 판단
    ① 규칙: ignore → 버림 / vip·keywords → 중요 / Gmail 프로모션·소셜 탭 → 버림
    ② 남은 메일만 AI: 보낸사람·제목·본문 앞 300자 (도구를 끈 상태로 호출)
    ③ 중요하면 말풍선 → [자세히] → 메일 탭 → [메일 열기]
```

- **알림까지 걸리는 시간**: 보통 1~2분입니다. IDLE을 5분마다 다시 걸기 때문에, 절전에서 깨어나 연결이 끊겨 있어도 늦어도 5분 안에 다시 붙습니다.
- **읽기 전용**: 받은편지함을 읽기 전용으로 열고, 메일에 '읽음' 표시를 남기지 않습니다. 지우기·보내기·라벨 바꾸기 코드는 없습니다.
- **처음 켤 때**: 그때까지 와 있던 메일은 건너뛰고, 켠 뒤에 온 메일부터 봅니다.
- **꺼져 있던 동안 온 메일**: 다음에 켜면 목록에는 들어오고, 12시간 이내에 온 것만 알립니다.
- **같은 대화**: 답장이 이어져도 같은 스레드는 6시간에 한 번만 알립니다.
- **조용히 할 때**: `quiet_hours`, 전체 화면, 방해 금지 모드에서는 말풍선 없이 캐릭터에 배지만 띄웁니다.
- **AI 판단이 실패하면**: Gmail이 붙인 '중요' 표시를 따릅니다. `ai = false`면 항상 그렇게 합니다.
- **거른 메일**: 메일 탭 아래 "거른 메일"에서 AI가 안 중요하다고 본 메일과 그 이유를 볼 수 있습니다. 판단이 자주 틀리면 `criteria`·`vip`·`ignore`를 고치세요.
- **아침 브리핑**: 어제 18시부터 온 중요 메일을 일정 아래에 보여줍니다. AI 요약을 다시 거치지 않고 메일 목록에서 바로 가져옵니다.

## 4. 보내는 데이터

- 메일은 내 PC가 메일 서버에서 직접 받습니다. 중간 서버는 없습니다.
- 규칙으로 정해지지 않은 메일만 보낸사람·제목·본문 앞 300자를 고른 AI(Claude 또는 ChatGPT, 내 구독)에 보냅니다. 이것도 싫으면 `ai = false`로 두세요.
- 메일 목록은 `%LOCALAPPDATA%\POPME\popme.db`에 `keep_days`(14일) 동안만 남습니다. 로그에는 메일 개수만 남고 제목·내용은 남지 않습니다.

## 5. 다른 메일

IMAP과 앱(애플리케이션) 비밀번호를 지원하면 `host`만 바꿔서 쓸 수 있습니다. Gmail 분류 탭, '중요' 표시, [메일 열기] 링크는 Gmail에서만 됩니다. 다른 메일에서 링크를 쓰려면 `web_url`에 웹메일 주소를 넣으세요.

| 메일 | host | 준비 |
|---|---|---|
| 네이버 | `imap.naver.com` | 메일 환경설정 → POP3/IMAP 설정 → IMAP 사용. 2단계 인증을 쓰면 애플리케이션 비밀번호 |
| 다음 | `imap.daum.net` | 메일 설정 → IMAP/POP3 → IMAP 사용 |
| Outlook·Hotmail | — | Microsoft가 비밀번호 방식 IMAP을 막아서(OAuth만 허용) 지원하지 않음 |

## 6. 안 될 때

메일 탭 맨 위에 연결 상태가 나옵니다.

- **로그인 실패 — 앱 비밀번호 확인**: 비밀번호를 다시 만들어 넣고 POPME를 다시 켜세요. 로그인 실패 뒤에는 30분마다 다시 시도합니다.
- **다시 연결 중**: 네트워크가 끊긴 상태입니다. 30초부터 시작해 최대 10분 간격으로 혼자 다시 붙습니다.
- 자세한 내용은 `%LOCALAPPDATA%\POPME\popme.log`의 "메일" 줄을 보세요.
